# v1.0.0

Initial public release.

- Automatic sale of safe grey-quality loot for normal vendor value.
- Inventory-full support by integrating with `Player::StoreLootItem()`.
- Persistent per-character `.autosell on/off` setting.
- `.autosell now` manual bag cleanup.
- Level-6 unlock/default enable behavior.
- Quest, key, quest-starter, loot-container, no-destroy, zero-value, and active-quest safeguards.
- Bot exclusion and money-cap protection.
